Resumo da operação

Quem opera
  • • Operador final (segurança): usa Forma 1 e 2 — liga/desliga rápido na visualização
  • • Admin do cliente: usa Forma 3 — configura objetos, confidence, tripwires
  • • Integrador: define tier vendido por câmera (Forma 3 painel topo)
Persistência
  • • Toggle global salva em UserPreferences.aiOverlay
  • • Toggle por câmera salva em Camera.aiEnabled
  • • Tier+configs salvam em Camera.aiConfig JSON
Quando NÃO ver bbox
  • • Tier não inclui IA
  • • aiEnabled = false
  • • Toggle global desligado (preferência usuário)
  • • Worker desconectado (mostra ⚠ "IA indisponível")
