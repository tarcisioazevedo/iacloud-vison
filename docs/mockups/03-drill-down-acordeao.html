📐 Princípios deste padrão

  • ✓ Drill in-place — usuário não sai da página; expande e contrai conforme precisa
  • ✓ Cada nível é navegável via URL (`/clientes/:id/sites/:id/boxes/:id`) para deep-link
  • ✓ Ações contextuais aparecem em cada nível ("+ site" só dentro de cliente, "+ box" só dentro de site, etc.)
  • ✓ Health score em cada nível dá orientação visual rápida (●98 verde / ●72 âmbar / ●40 rosa)
  • ✓ Câmera avulsa é cidadã de primeira classe, exibida no nível do site mas fora da box
  • ✓ RBAC server-side — backend filtra automaticamente o que cada persona vê
