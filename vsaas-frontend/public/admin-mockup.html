Como funciona o DNS personalizado
1. O integrador aponta um CNAME de seu domínio para vsaas.com.br
2. O Caddy intercepta via on_demand_tls e consulta /internal/domain-check
3. Se o domínio existe no model CustomDomain, o certificado Let's Encrypt é emitido automaticamente
4. O frontend detecta o hostname e carrega o white-label correspondente
